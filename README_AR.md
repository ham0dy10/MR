# تعديل السيرة الذاتية والشهادات

افتح ملف `profile-content.js` الموجود بجذر الموقع. نفس الملف يتحكم بالنسختين العربية والإنكليزية.

## السيرة الذاتية

1. ضع ملف الـPDF الذي تختاره داخل مجلد `assets`.
2. غيّر قيمة `cvPdf`، مثل `cvPdf: "assets/my-cv.pdf",`.
3. افتح الرئيسية أو النبذة حتى تتأكد أن الزر يحمل ملفك. لتحديث السيرة بدّل الملف بنفس الاسم، أو حدّث المسار. لإخفاء الزر اجعل القيمة `cvPdf: "",`.

## الشهادات

كل عنصر داخل `certificates` هو شهادة. انسخ أحد العناصر وأضف بيانات الشهادة، أو احذف العنصر كاملًا لحذفها. اترك فاصلة بين العناصر.

```js
{
  title: { en: "Certificate title", ar: "اسم الشهادة" },
  issuer: "جهة الإصدار",
  url: ""
}
```

ضع في `url` رابط التحقّق أو مسار ملف الشهادة، مثل `assets/certificates/course.pdf`. اتركه فارغًا إذا كنت تريد عرض الشهادة بدون رابط. إذا جعلت القائمة `certificates: []` يختفي عمودا الشهادات والتعلّم والتطبيق.

لإظهار عنصر في عمود «التعلّم والتطبيق»، أضف إليه `group: "learning"`. ويمكنك إضافة وصف اختياري مثل `description: { en: "English text", ar: "وصف بالعربي" }`. تظهر بقية العناصر في عمود الشهادات.
